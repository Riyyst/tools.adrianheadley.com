About

Privacy-first tools that run entirely in your browser.

The Mission

Welcome to tools.adrianheadley.com, a growing collection of practical utilities designed for everyday tasks, productivity, privacy and experimentation.

I build tools that I find useful in day-to-day life and share them openly so others can use, inspect and learn from them. The site also includes a curated collection of useful external websites created by others.

Privacy and Transparency

  • Browser-only processing — Every tool hosted on this website runs entirely inside your browser. Files, text and other information are processed on your device and are not sent to a processing server.
  • Hosting only — The website server only delivers the HTML, CSS, JavaScript and other files needed to open the site. It does not process, store or retain the information you use within the tools.
  • No data collection — No tool data is saved, logged or retained. There are no user accounts and no information is sold, shared or used to build profiles.
  • No analytics or tracking — The website does not use analytics services, tracking pixels or behavioural monitoring.
  • No cookies — The website does not use cookies for analytics, advertising, personalisation or tracking.
  • Open source — The code is openly accessible and can be inspected directly, allowing users to see how each tool works and confirm that processing happens locally.

What You Can Expect

  • Private — Tools designed to work locally without uploads, accounts or tracking.
  • Reliable — Simple utilities that are focused, dependable and easy to use.
  • Transparent — Accessible source code and clear explanations of how the tools work.
  • Useful and enjoyable — A mixture of practical utilities and lighter experiments.

External Websites

The Powerful Websites directory contains links to independent third-party websites. Those websites are separate from tools.adrianheadley.com and may use their own servers, cookies, analytics or privacy practices.

The Roadmap

The collection will continue to grow with new browser-based utilities, improvements to existing tools and additional useful resources.
