Random Spinner

Add choices, adjust their weights, then spin the wheel to select a random winner.

About this tool

What it does

Choose a random result from your own list using a weighted spinning wheel.

How to use it

  1. Add the choices you want on the wheel.
  2. Adjust weights if some choices should be more or less likely.
  3. Spin to select a result, or save, load or share the configured list.

Privacy and processing

Spinner choices and weights are handled in your browser. Setup links contain the list you choose to share.
