URL Lengthener

Paste a link, lengthen it and copy the result.

About this tool

What it does

Create a deliberately longer version of a URL for novelty or testing.

How to use it

  1. Enter the URL you want to lengthen.
  2. Run the lengthening tool.
  3. Copy the resulting URL.

Privacy and processing

URL lengthening is performed in your browser. The source URL is not intentionally sent to a shortening or redirect service.
