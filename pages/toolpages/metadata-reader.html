About this tool

What it does

Inspect available EXIF, IPTC and XMP metadata from supported files without sending the file to a remote metadata service.

How to use it

  1. Choose the file you want to inspect.
  2. Wait for the metadata to be read.
  3. Review or copy the available fields and view mapped GPS information when present.

Privacy and processing

Metadata parsing is performed locally. If GPS data is displayed on a map, map tiles may be requested from OpenStreetMap services.
