PDF Separator

Split one PDF into individual pages, selected pages or repeating groups of pages directly in your browser.

Choose a PDF to begin.

Each selected page is saved as its own PDF. Use commas and ranges, such as 2-5, 1,4,9, or leave blank for all pages.

The document will be separated repeatedly in groups of this many pages. Any pages left at the end are placed into the final PDF.

Choose a PDF to preview the groups.
Rename grouped PDFs Choose how you want to name the grouped files.
Manual naming Edit each filename directly.
Intelligent naming Analyse every grouped PDF, then build a filename like a mail merge using reliable fields found in all groups.

Analyse the grouped PDFs first. Only reliable fields found in every grouped PDF will be available.

Available intelligent fields Choose any reliable field found in every grouped PDF.

Type normal text anywhere. For example [NAME] - Contract, [LASTNAME], [FIRSTNAME] - Contract, or [EMPLOYER] - [DOCUMENT_TYPE].
